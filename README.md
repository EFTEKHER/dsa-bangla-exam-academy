# DSA Bangla Exam Academy

Interactive, bilingual (বাংলা + English) Data Structure & Algorithm course for Bangladesh Bank, BCS, BPSC, Combined Bank, NTRCA and other govt IT officer written exams.

- 18 chapters, every idea explained line by line in English and Bangla
- 19 visualizers: sorting (6 algorithms), searching, array, linked list, stack, queue, tree traversals, BST, heap, BFS/DFS, Prim/Kruskal, Dijkstra, Tower of Hanoi, recursion call stack, infix to postfix, Big-O growth
- Past written questions with model answers, searchable by exam board
- 20-question timed mock test, final revision sheet, progress saved in the browser

## Run locally

No build step. Serve the folder with any static server:

```
npx serve .
```

## Structure

- `index.html` – shell
- `css/style.css` – theme (light and dark)
- `js/core.js` – router, rendering, quiz, progress
- `js/viz.js` – all visualizers
- `js/data1.js`, `js/data2.js`, `js/data3.js` – chapter content, mock-test pool, revision sheet
